# MAIN 上位机：Chirp 参数、RX 波形与 FPGA 峰值

直接双击本目录 **`RunMain.cmd`**。也可以运行 `UsMimoTestBench/bin/Release/UsMimoTestBench.exe`。Release 和 Debug 均已更新；以前的 `bin/Chirp200k` 是历史版本，不用于本次 main 峰值测试。

本次只修改 `03_SW` 上位机，复用 FPGA 已有的 64 字节 UART 设置协议。FPGA RTL 和已发布的 main `.sof` 没有变化；如果板上已烧录最新 main，就无需为这次软件更新重新烧录。板上仍须使用 main revision `UsMimoTestBench`，不是独立 Chirp 或独立 FFT 实验固件。

## 使用步骤

1. 主板 USB-C 接电脑、供电并打开 S1；关闭 MainFftMonitor、旧上位机和其他占用同一 COM 的程序。
2. 打开新上位机，点击「刷新」，选择主板 COM，点击「连接主板」。连接本身不会触发发射。
3. TX 默认：中心 **40 kHz**、带宽 **4 kHz**、时长 **20 ms**、幅度系数 **0.25**。中心/带宽输入单位是 **kHz**，不是 Hz。
4. 「仅应用 TX 参数」发送设置；「应用并采集一次」依次发送完整设置包和触发命令。设置在运行时生效，不需要重新编译 FPGA。
5. 初次 RX/FFT 测试，用外部发生器持续输出小幅 **100 Hz** 正弦，接主板 P5 RX_IN，并共地。波形显示 RX 的 ADC 采样，右上角显示 FPGA 算出的峰值和功率。
6. RX 参考频率填写发生器当前频率，仅用于计算误差；它不会控制发生器，也不会修改 FPGA 的峰值结果。
7. 可勾选连续采集，软件会等待一帧波形和峰值完整接收后，再间隔约1秒发起下一帧。断开连接即停止；取消勾选会停止后续触发，当前帧仍接收完。

FPGA 当前协议没有设置确认/参数回读报文，所以界面明确显示「设置包已发送」，不将它当作硬件确认。实际 TX 模拟波形仍可用示波器核对。程序不打开 JTAG，也不会自动烧录。

## 固定的 RX 与 FFT 配置

现有协议每次发送整个设置包，并非只发送 TX 字段。新版上位机始终在包中保留当前 main 的这些值：

| 参数 | 值 |
|---|---|
| 自动触发 | FPGA 自动触发关闭，由软件逐帧触发 |
| TX 波形/采样 | 正弦 Chirp、14 位、不降采样、TX 滤波旁路、1倍通路 |
| RX 接收窗口 | 250 ms |
| RX 延迟 | 1 ms |
| RX 回传抽取 | 参数3，即每4点保留1点 |
| RX 格式/模拟通路 | 16 位，Mux=4（沿用 main 默认） |
| FFT | FPGA 原配置：CIC /32、8192点、35.807 kS/s、25–500 Hz搜索 |

FFT 点数、抽取和搜索范围不是这四个 TX 参数的一部分，本程序不改变它们。TX 时长改变也不会改变 RX 250 ms。真实超声混频信号的有效时间取决于 TX/RX 重叠；本次低频测试先使用持续的外部发生器信号。

## 输入范围

- 中心频率：0.001–1000 kHz；带宽：0–1000 kHz；整个扫频范围须大于0且不超过1000 kHz。
- 带宽设0可生成单频正弦。
- 时长：0.01–100 ms。当前 MainTxController 对较大的计数有钳位，本软件避免发送会触发该钳位的长时长值。
- 幅度系数：0–1，默认0.25。这个系数不是输出电压的伏特数。
- 这些是软件可输入范围，不代表模拟前端和换能器已经在整个范围完成实测。

## 波形与结果

- 波形横轴从本帧第一个回传点开始计时（ms），不是TX发射起点或传播延迟；纵轴为 ADC 数字码减去32768后的值，未标定成伏特。main 默认一帧约71,614点。
- 在图上滚轮缩放，按住鼠标左键拖动平移；「完整波形」恢复整个接收窗，「前10ms」查看细节。缩小显示时使用每像素最小/最大值，保留局部峰值。
- 「导出波形CSV」保存全部原始点，不是屏幕抽稀后的点，包含 unsigned/signed码和真实时间间隔。
- 峰值频率由 FPGA 返回的 bin 与已知采样率换算，FFT/找峰仍在 FPGA 上完成。PC 没有另做FFT来替代硬件结果。
- 功率显示为 `M1.power / 64`，单位 **ADC code²**，不是瓦特或声功率。
- 当前 FPGA 不回传完整频谱，因此界面显示 RX 时域波形和峰值结果，不伪造完整频谱图。
- ADC削顶、FFT溢出、采样不足、采样间隔不符、缓存超限等会标成无效结果。超时或帧配对异常需断开重连，避免把上一帧误当成新测量。
- 峰值历史自动保存在 EXE 旁的 `DataSessions/日期时间_编号/peaks.csv`；包含本帧 TX 请求参数、RX参考值和状态。
- 「离线演示」使用合成100Hz数据，不连接硬件；标题、状态、CSV来源均会注明演示。

## 修改代码与编译

使用原 `UsMimoTestBench/UsMimoTestBench.sln`。项目现使用 **.NET Framework 4.8**，本机已有对应SDK与Visual Studio 2022，无第三方运行库。
