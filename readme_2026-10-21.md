# Main 搜峰扩展与距离扫描（2026-10-21）

仅把Main默认搜索上限从500 Hz改为2000 Hz，下限保留25 Hz。对应1024点FFT的第1–57格。

TX仍为40 kHz中心、4 kHz带宽、20 ms、幅度0.25；RX延迟1 ms、窗口19 ms；原始ADC速率、CIC /32、672有效点、Kaiser4、补零至1024点、FPGA插值和165/50 MHz时钟全部不变。独立Chirp和低频FFT实验不改。

## 配置入口

编辑 `02_RTL/V0/Simulation/FFT/main_settings.json` 的 `search_max_hz`，运行同目录 `configure_main.py`。生成器同步生成MainSettings.vhd、MainProtocol.cs里的搜索常量和MainFftMonitor的范围常量。GUI范围检查、参考频率输入上下限及说明读取这些常量。

修改配置后仍需重新编译Main和03_SW，并重新下载SOF。上位机参考频率输入不控制硬件搜峰范围。

## 验证

- 10–75 cm，每2.5 cm一点，共27点。理想单回波模型下最大绝对距离误差0.467 mm，RMSE 0.226 mm。
- 75 cm理想拍频874.636 Hz，新输出874.794 Hz，换算距离约75.0136 cm。
- 新旧ADC输入、CIC采集和全部FFT功率谱完全相同，前14点频率输出相同；远距离改善来自搜峰范围修改。
- 生产RTL采用Intel内存模型通过数值/报文检查，1136组插值测试通过，上位机自测和27帧解析比对通过。
- Main编译和时序结果以本次报告checks.json及output_files/build_checks.json为准。

这是仿真误差，不是新增实板测距精度结果。25 Hz的短窗限制、多径和换能器频响问题仍然存在。
