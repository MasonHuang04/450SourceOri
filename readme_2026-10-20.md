## 最后一次workflow核对

当前代码已在同一Main顶层连接：上位机参数/触发 → Chirp生成/DAC → 外部发射与混频硬件 → ADC → CIC/去直流/Kaiser4/FFT/功率峰值/插值 → UART波形与M3结果 → 上位机显示频率。外部硬件正常由用户反馈，代码核对不替代新的声学精度测量。
