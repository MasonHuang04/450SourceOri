新版固件确实会进行第二次乘法

顶层UsMimoTestBench.vhd的MainDigitalMixer输入为cFullValue及配对正弦参考cFullReference，输出cMixedValue直接接MainFftProcessor；不存在自动检测已混频输入并跳过乘法的模式。主板模拟低通默认旁路，不能把前端Rx_Mix理解为必然只含低频。

正确新版：RX → Rx_Amp → ADC → FPGA × 正弦参考 → CIC低通 → FFT
错误组合：RX → 前端 × TX → Rx_Mix → ADC → FPGA再次 × 正弦参考 → CIC低通 → FFT

理想双极、零均值方波q与同源正弦s满足q·s与|cos(phi)|成比例。将已混频信号q·r再次乘s，主要仍是载波及高频项，低通后不会保留预期的目标拍频。纯低频IF再次乘40kHz参考，也会被搬回高频。

为什么会有残留载波

AD835并非理想零串扰乘法器，数据手册给出了输入失调及X/Y馈通规格。如果实际参考方波带直流分量，(q+b)r中会包含b·r，即原始RX载波。有限馈通也能形成类似项。再次数字混频时，这部分r可产生正常拍频。实际残留量需测量。

项目调试记录写过“乘法器会引入偏置”。这不能直接证明存在上述RX残留：单纯输出端常量DC不是目标载波，乘40kHz参考后主要产生40kHz项；需要区分输入偏置、参考直流分量和载波馈通。AD835官方数据手册
